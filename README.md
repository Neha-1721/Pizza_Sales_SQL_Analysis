# 🍕 Pizza Sales Analysis | SQL & Power BI

## 📌 Project Overview
This project analyzes pizza sales data to understand overall business performance, customer ordering patterns, and product-level sales performance.

SQL was used to perform data analysis and calculate key business metrics, while Power BI was used to create an interactive dashboard for visualizing the insights.
## 🛠️ Tools & Technologies
* SQL
* Power BI
* Excel / CSV

## 🎯 Key Objectives
* Analyze overall pizza sales performance
* Calculate important business KPIs
* Identify daily and monthly order trends
* Analyze sales contribution by pizza category and size
* Identify top-performing pizzas based on revenue
* Identify low-performing pizzas based on total orders
* Build an interactive Power BI dashboard

## 📊 Key KPIs

### Total Revenue
Total revenue generated from pizza sales.

### Total Orders
Total number of unique orders placed.

### Total Pizzas Sold
Total quantity of pizzas sold.

### Average Order Value
Average amount spent per order.

**Formula:**
Average Order Value = Total Revenue / Total Orders

### Average Pizzas Per Order
Average number of pizzas sold per order.

**Formula:**
Average Pizzas Per Order = Total Pizzas Sold / Total Orders
## 📈 Analysis Performed

### 1. Daily Trend for Total Orders
Calculated the total number of orders placed each day to analyze daily ordering patterns.

### 2. Monthly Trend for Total Orders
Calculated monthly total orders to track sales performance over time.

### 3. Percentage of Sales by Pizza Category
Calculated the sales contribution of each pizza category as a percentage of overall sales.

### 4. Percentage of Sales by Pizza Size
Calculated total sales and percentage contribution for each pizza size.

### 5. Percentage of Sales by Pizza Size – Quarter 1
Filtered the data for Quarter 1 and calculated total sales and percentage contribution for each pizza size.

### 6. Top 5 Best Sellers by Revenue
Identified the top 5 pizzas generating the highest revenue.

### 7. Bottom 5 Best Sellers by Total Orders
Identified the bottom 5 pizzas based on the lowest number of orders.
